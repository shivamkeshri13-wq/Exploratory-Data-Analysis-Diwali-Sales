# 🪔 Exploratory Data Analysis - Diwali Sales

## 📌 Project Overview
This project focuses on performing **Exploratory Data Analysis (EDA)** on a Diwali Sales dataset using Python.  
The objective is to analyze customer purchasing behavior and identify key insights that can help improve sales strategies during festive seasons.

Through this analysis, we explore:
- Customer demographics
- Purchasing patterns
- Product category performance
- State-wise sales trends
- Gender and age group analysis

---

## 📂 Dataset
The dataset contains customer purchase information during the Diwali festival season.

### Dataset Features:
- User ID
- Gender
- Age Group
- State
- Occupation
- Product Category
- Orders
- Amount

The following analysis was performed in this project:

- Gender-wise purchasing analysis

---

## 📈 Key Insights

- Married women age group 26-35 years contributed the most to sales.
- Customers from Uttar Pradesh, Maharashtra, and Karnataka made the highest purchases.
- IT, Healthcare, and Aviation sectors showed strong buying behavior.
- Food, Clothing, and Electronics categories generated high sales.
